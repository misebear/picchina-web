교과서 표현을 시험 전까지 암기

중국어·병음·한국어 뜻을 카드로 저장하고 발음과 퀴즈를 반복하는 흐름이 필요합니다.

OCR이 틀린 글자를 수정

학습 자료는 한 글자 오류도 그대로 외울 수 있습니다. 저장 전에 중국어, 병음, 뜻을 직접 고칠 수 있어야 합니다.

틀린 표현만 다시 보기

전체 번역을 다시 읽는 대신 오답과 오래된 카드만 추려 보는 편이 복습 시간을 줄여 줍니다.

찍으면 중국어를 선택할 때 확인할 범위

이 앱은 지금 배우는 교재의 필요한 중국어를 직접 확인하고 카드로 정리해 반복 복습하는 도구입니다. 범용 문장 번역을 제공하지 않으며, 62개 내장 사전에 없는 뜻은 직접 보완해야 할 수 있습니다.

처음에는 샘플 5장으로 발음·뜻·퀴즈 흐름을 보고, 자신의 교재 일부로 입력 부담을 확인해 보세요. 웹의 퀴즈는 정답을 확인한 뒤 맞음과 틀림을 표시하는 자기평가입니다. Android 앱은 카드 구성에 따라 자동 채점 객관식 문제와 반복 복습을 제공합니다.

찍으면 중국어의 학습지 복습 순서

  1. 교과서나 프린트를 밝고 반듯하게 촬영합니다.
  2. OCR 후보에서 실제로 배운 표현만 남깁니다.
  3. 중국어·병음·뜻을 원본 학습지와 대조합니다.
  4. 발음을 듣고 플립카드와 퀴즈로 떠올려 봅니다.
  5. 틀린 카드와 오래된 카드를 다음 복습에서 다시 봅니다.

OCR과 자동 뜻은 초안입니다. 인명, 고유명사, 긴 문장, 흐린 사진은 원본과 반드시 대조하세요.
