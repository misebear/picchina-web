찍으면 중국어병음과 성조 가이드
앱 소개웹 체험 가이드 커리큘럼 샘플 지원

Pronunciation

병음은 한글 발음표가 아니라 소리를 찾는 지도입니다

중국어 발음은 한글로 완전히 옮기기 어렵습니다. 그래서 초급 단계에서는 병음을 “외울 글자”가 아니라 듣기와 말하기를 연결하는 표시로 다루는 것이 좋습니다.

성조를 먼저 과장해서 연습하기

처음부터 자연스럽게 말하려고 하면 성조가 평평해지기 쉽습니다. 1성은 길고 평평하게, 2성은 질문처럼 올리고, 3성은 낮게 눌렀다가 살짝 올리고, 4성은 짧게 떨어뜨립니다. 과장해서 연습한 뒤 문장 속에서 조금 줄이는 편이 안전합니다.

한국어 화자가 자주 헷갈리는 소리

병음주의점연습 예

짧은 문장으로 연결하기

단어 하나씩만 들으면 성조가 맞아도 문장에서는 다시 무너질 수 있습니다. “你好”, “谢谢你”, “我叫...”처럼 짧은 문장을 선택해 두 번 듣고 한 번 따라 말하는 식으로 연습합니다.

앱에서 발음을 들을 때

  • 처음에는 보통 속도보다 느린 속도로 듣습니다.
  • 한 문장을 세 번 이상 반복하기보다 틀린 성조만 따로 빼서 듣습니다.
  • 뜻을 먼저 외운 뒤 발음을 듣는 것보다, 소리를 들으며 뜻을 같이 확인하는 편이 오래갑니다.
외부 사이트의 음원을 무단 수집하거나 다운로드하지 않습니다. 발음 연습은 기기 내 TTS 또는 사용자가 명시적으로 선택한 합법적인 TTS 제공자를 기준으로 합니다.

중국어 발음이 나오지 않을 때

  1. 휴대전화의 미디어 음량과 연결된 이어폰·블루투스 기기를 확인합니다.
  2. 기기 설정에서 텍스트 읽어주기(TTS) 엔진과 중국어 음성 데이터를 확인합니다. 설정 이름과 설치 방법은 제조사·엔진에 따라 다릅니다.
  3. 음성 데이터를 준비한 뒤 앱에서 발음 버튼을 다시 누릅니다. 네트워크가 필요한 음성도 있습니다.
  4. 웹 체험은 브라우저가 제공하는 중국어 음성을 사용합니다. 음성이 지원되지 않아도 카드의 글자와 뜻으로 학습을 계속할 수 있습니다.

기본 발음은 기기의 Android TTS입니다. 선택적 Cloud TTS는 본인의 API 키와 전송 동의가 필요한 별도 기능이며 첫 학습에 필요한 설정은 아닙니다.

실전 연습용 항목은 샘플 학습지에서 볼 수 있습니다.
