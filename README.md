# PicChina public web

Generated from the private PicChina application repository. This repository contains only the public static website.

## 공개 사이트

[찍으면 중국어 홈페이지](https://misebear.github.io/picchina-web/)에서 Android 앱의 실제 화면과 사용 흐름을 보고, [샘플 카드 5장](https://misebear.github.io/picchina-web/demo/)을 체험할 수 있습니다. 이 저장소에는 생성된 HTML, CSS, JavaScript, 예시 자료와 공개 홍보 미디어가 들어 있습니다. Android 앱 소스나 빌드·서명 자료는 포함하지 않습니다.

`VERSION`의 현재 값은 `0.1.1`이며 공개 웹의 버전입니다. Google Play 앱의 버전, 업로드, 심사 또는 공개 상태를 나타내지 않습니다.

## 홈페이지 영상 사용법

- 첫 화면의 8초 영상은 실제 Android 앱 화면을 발췌한 무음 반복 시연입니다. 화면에 충분히 보일 때 재생하고, 화면 밖으로 나가거나 탭이 숨겨지면 멈춥니다.
- 동작 줄이기(`prefers-reduced-motion`) 또는 데이터 절약(`saveData`)을 사용하면 자동 재생을 억제합니다. 사용자는 **시연 재생**을 눌러 직접 시작할 수 있습니다. **시연 일시정지**를 누른 뒤에는 화면을 오가도 자동으로 다시 시작하지 않습니다.
- **소리와 함께 30초 보기**를 누르면 내레이션과 한국어 자막이 있는 영상을 엽니다. 이 동작 전에는 전체 영상이나 자막을 불러오지 않습니다. 내레이션과 발음 예시는 홍보용 합성 음성으로, 앱의 실제 기기 음성과 다릅니다.
- 영상 로딩에 실패하면 정지 화면과 글 설명을 이용할 수 있습니다. 전체 영상에는 **영상 다시 불러오기** 버튼을 제공하며, 닫은 영상의 뒤늦은 재생 완료가 오디오를 다시 시작하지 않도록 처리합니다.

## Android 앱과 웹 체험의 차이

| 기능 | Android 앱 | 웹 체험 |
| --- | --- | --- |
| 교재 사진 가져오기·인식 | 지원, 인식 결과 확인 필요 | 제공하지 않음 |
| 중국어·병음·뜻 확인과 편집 | 필요한 항목을 확인해 카드 저장 | 샘플 5장 편집 가능 |
| 뜻 채우기 | 내장 사전과 일치하는 항목, 없는 뜻은 직접 입력 | 샘플 체험이며 문장 번역 서비스가 아님 |
| 발음 | 기기의 Android 중국어 음성 지원·설정에 영향받음 | 브라우저의 음성 지원에 영향받음 |
| 퀴즈 | 선택지를 만들 수 있으면 자동 채점, 어려우면 자기평가 | 자기평가 |
| 편집 내용 유지·이동 | 앱에서 카드 저장 | 새로고침하면 사라짐, 텍스트 복습 노트 다운로드 가능, 앱으로 자동 전송되지 않음 |

## 배포 경로와 파일 검증

GitHub Pages 프로젝트 경로는 `/picchina-web/`입니다. `site-config.json`의 `base`와 `publicUrl`이 이 경로를 지정하며, HTML의 에셋 링크도 이 접두사를 사용합니다. 다른 경로에 배포하려면 원본 웹 프로젝트에서 해당 base로 다시 빌드해야 합니다. 이 생성물에는 빌드용 소스와 패키지 설치 명령이 포함되지 않습니다.

`deployment-manifest.json`은 공개 payload의 파일 경로, 크기와 SHA-256을 기록합니다. 현재 `sourceDirty: true`는 원본의 미커밋 변경을 포함해 검증한 생성물이라는 뜻이므로, `sourceCommit` 하나만으로 동일한 결과를 재현할 수 있다고 해석하면 안 됩니다. payload를 확인할 때는 각 파일을 manifest의 해시와 비교하세요. README와 변경 기록은 payload 목록과 별도로 관리합니다.

2026-10-09 배포 준비 검증에서는 원본 웹 프로젝트의 테스트 13개가 통과했고, `/picchina-web/`와 `/` 두 빌드의 HTML을 각각 16개씩 검사했습니다. 이 결과는 빌드·동작 검사이며, 공개 URL의 배포 완료나 Google Play 앱의 공개 완료를 뜻하지 않습니다.

웹 변경 내용은 [CHANGELOG.md](CHANGELOG.md)를 참고하세요.
