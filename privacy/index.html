Privacy Policy

찍으면 중국어 개인정보 처리방침

시행일: 2026년 5월 19일

1. 앱의 기본 원칙

찍으면 중국어는 중국어 학습지 사진에서 학습 항목을 만들고, 병음과 한국어 뜻, 발음 학습, 퀴즈, 복습 자료 생성을 돕는 학습 앱입니다. 학습지 사진과 OCR 결과, 편집한 학습 항목은 기본적으로 사용자의 기기 안에만 저장됩니다.

2. 접근하거나 저장하는 정보

  • 카메라와 사진: 사용자가 직접 촬영하거나 선택한 학습지 이미지를 OCR 처리하기 위해 사용합니다.
  • 학습 데이터: 중국어 원문, 병음, 한국어 뜻, 퀴즈 기록, 생성 파일 경로를 기기 로컬 데이터베이스에 저장합니다.
  • 광고 및 동의 정보: Google AdMob 및 UMP SDK가 광고 제공, 동의 관리, 부정 이용 방지에 필요한 기기/광고 관련 정보를 처리할 수 있습니다.
  • 선택적 Cloud TTS: 사용자가 앱 설정에서 명시적으로 켠 경우에만 발음 생성을 위해 학습 문구가 설정된 TTS 제공자에 전송될 수 있습니다.

3. 서버 업로드 및 외부 음원

기본 기능은 학습지 이미지를 자체 서버에 업로드하지 않습니다. 네이버 사전, Forvo, 유튜브, 블로그 등 외부 사이트의 음원을 스크래핑하거나 자동 다운로드하지 않습니다. 발음은 Android TextToSpeech 또는 사용자가 동의한 합법적인 TTS 제공자만 사용합니다.

4. 광고

앱은 Google AdMob 광고만 사용합니다. 학생 안전 광고 모드는 기본으로 켜져 있으며, 아동/청소년 보호 설정과 낮은 광고 콘텐츠 등급을 우선 적용하도록 설계되어 있습니다. 광고는 학습 흐름을 방해하지 않도록 제한된 위치와 빈도로만 표시됩니다.

5. 보관 및 삭제

사용자는 앱의 히스토리 화면에서 저장된 학습 세션과 생성 파일 기록을 삭제할 수 있습니다. 앱을 삭제하면 기기 안에 저장된 로컬 앱 데이터도 함께 제거됩니다.

6. 문의

개인정보 관련 문의는 Google Play 스토어에 표시된 개발자 연락처를 통해 접수할 수 있습니다.

7. 선택적 로컬 진단 및 설치 유입 정보

앱은 기능 점검을 위해 이벤트 횟수·시각·앱 버전·학습 경로(샘플 또는 본인 자료)와 임의의 이벤트/실행 식별값을 기기 안에 기록합니다. 학습지 문장·사진·학습장 이름·계정·광고 ID·하드웨어 기기 ID를 이 진단 기록에 넣지 않습니다. 최근 이벤트는 최대 200개로 제한됩니다.

Google Play Install Referrer를 통해 확인 가능한 설치 캠페인 코드만 기기에 보관합니다. 확인할 수 없는 유입은 unknown으로 처리합니다. 앱 자체의 분석 서버로 자동 전송하지 않으며, 사용자가 설정에서 진단 JSON 공유를 선택한 경우에만 선택한 공유 대상에 파일을 전달합니다. 광고 SDK의 별도 처리는 위 광고 안내를 따릅니다.

웹 체험의 이벤트 기록은 브라우저 저장소 또는 메모리에만 보관하고 자동으로 전송하지 않습니다. 사이트 데이터를 삭제하면 브라우저 진단을 지울 수 있습니다. 웹에서 편집하는 학습 카드 자체는 페이지 메모리에 있으며 새로고침하면 초기화됩니다.

앱을 삭제하면 앱 내부의 로컬 진단이 제거됩니다. 다른 앱이나 공유 저장소로 내보낸 파일은 해당 위치에서 별도로 삭제해 주세요.

8. 기기의 자동 백업

Android 앱은 운영체제의 앱 데이터 백업을 허용하는 설정을 사용합니다. 기기·계정의 백업 설정과 운영체제 정책에 따라 앱 데이터가 운영체제 백업에 포함되거나 재설치 후 복원될 수 있습니다. 앱이 별도의 자체 동기화 서버를 운영한다는 뜻은 아닙니다. 백업 보관과 삭제는 기기 및 백업 서비스 설정에서도 확인해 주세요.

지원과 데이터 삭제 안내는 지원 페이지에서 볼 수 있습니다.
