Support

지원, 데이터 삭제, 자주 묻는 질문

앱과 웹 데모를 사용할 때 자주 생기는 질문을 정리했습니다. 개인정보나 데이터 삭제 요청은 Google Play에 표시된 개발자 연락처를 통해 접수할 수 있습니다.

자주 묻는 질문

사진이 서버에 올라가나요?

기본 사용에서는 학습지 사진과 편집한 학습 항목이 사용자의 기기 안에서 처리되고 저장됩니다. 별도 서버에 학습지 이미지를 업로드하는 기능을 기본으로 제공하지 않습니다.

웹 데모와 Android 앱은 무엇이 다른가요?

웹 데모는 샘플과 직접 입력 텍스트로 학습 흐름을 확인하기 위한 체험판입니다. Android 앱은 카메라, 사진 선택, 기기 저장소, 학습 히스토리 등 모바일 학습 흐름에 맞춘 기능을 제공합니다.

광고는 어디에 표시되나요?

웹사이트에는 승인 전 광고를 표시하지 않습니다. Android 앱의 광고는 학습 결과를 가리는 방식이 아니라 제한된 위치와 빈도로 운영하는 것을 원칙으로 합니다.

OCR 결과가 틀리면 어떻게 하나요?

비슷한 한자는 OCR이 틀릴 수 있습니다. 학습 항목 편집 화면에서 중국어 원문, 병음, 뜻을 직접 고친 뒤 학습과 퀴즈를 진행하세요.

데이터 삭제

앱 안의 히스토리에서 저장된 학습 세션과 생성 파일 기록을 삭제할 수 있습니다. 앱을 삭제하면 기기에 저장된 앱 로컬 데이터도 함께 제거됩니다. 추가 문의가 필요하면 Google Play 스토어의 개발자 연락처를 이용해 주세요.

문제 신고 시 알려주면 좋은 정보

  • 사용 중인 기기와 Android 버전
  • 문제가 생긴 화면 이름
  • OCR, 발음, 퀴즈, 복습 자료 중 어떤 단계에서 생겼는지
