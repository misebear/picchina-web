Support

지원, 데이터 삭제, 자주 묻는 질문

앱과 웹 데모를 사용할 때 자주 생기는 질문을 정리했습니다. 개인정보나 데이터 삭제 요청은 Google Play에 표시된 개발자 연락처를 통해 접수할 수 있습니다.

자주 묻는 질문

사진이 서버에 올라가나요?

기본 사용에서는 학습지 사진과 편집한 학습 항목이 사용자의 기기 안에서 처리되고 저장됩니다. 별도 서버에 학습지 이미지를 업로드하는 기능을 기본으로 제공하지 않습니다.

웹 데모와 Android 앱은 무엇이 다른가요?

웹 데모는 샘플과 직접 입력 텍스트로 학습 흐름을 확인하기 위한 체험판입니다. Android 앱은 카메라, 사진 선택, 기기 저장소, 학습 히스토리 등 모바일 학습 흐름에 맞춘 기능을 제공합니다.

광고는 어디에 표시되나요?

웹 체험에는 광고를 표시하지 않습니다. Android 앱의 광고는 학습 결과를 가리는 방식이 아니라 제한된 위치와 빈도로 운영하는 것을 원칙으로 합니다.

OCR 결과가 틀리면 어떻게 하나요?

비슷한 한자는 OCR이 틀릴 수 있습니다. 학습 항목 편집 화면에서 중국어 원문, 병음, 뜻을 직접 고친 뒤 학습과 퀴즈를 진행하세요.

데이터 삭제

앱 안의 히스토리에서 저장된 학습 세션과 생성 파일 기록을 삭제할 수 있습니다. 앱을 삭제하면 기기에 저장된 앱 로컬 데이터도 함께 제거됩니다. 추가 문의가 필요하면 Google Play 스토어의 개발자 연락처를 이용해 주세요.

문제 신고 시 알려주면 좋은 정보

  • 사용 중인 기기와 Android 버전
  • 문제가 생긴 화면 이름
  • OCR, 발음, 퀴즈, 복습 자료 중 어떤 단계에서 생겼는지
  • 개인정보가 포함되지 않은 오류 상황 설명

뜻이 없거나 원문을 수정했어요

뜻은 내장 사전과 일치하는 경우에만 채워집니다. 교재나 사전의 풀이를 보고 직접 입력할 수 있습니다. 중국어를 수정한 뒤에는 병음과 뜻을 다시 확인하고 검토 완료를 눌러 주세요. 입력한 값은 자동으로 덮어쓰지 않습니다.

음성·웹 체험 안내

중국어 TTS와 기기의 음성 데이터를 확인해 주세요. 자세한 점검 순서는 발음 안내에 있습니다. 웹에서는 새로고침하면 편집한 카드가 사라지므로 필요한 복습 노트를 먼저 내려받으세요.

로컬 진단과 삭제

앱의 선택적 진단 내보내기에는 이벤트 시각·임의 이벤트 식별값·앱 버전·학습 경로·캠페인 코드가 포함됩니다. 학습지 내용과 사진은 포함하지 않으며 자동으로 서버에 전송하지 않습니다. 웹 진단은 이 브라우저에만 보관되며 사이트 데이터 삭제로 지울 수 있습니다. 내보내거나 다른 앱에 공유한 파일은 해당 저장 위치에서도 별도로 삭제해 주세요.

개인정보 처리 기준은 개인정보 처리방침에서 확인할 수 있습니다.
